## Technical setup

Static HTML/CSS with a small, accessible client-side project filter (no build step required). Deploy with GitHub Pages from the `main` branch and repository root.

To run locally:

```bash
git clone https://github.com/jawharjoe/Portfolio-MMM.git
cd Portfolio-MMM
python3 -m http.server 8000
```

Open `http://localhost:8000`. Some project figures are sourced from the public Meridian repository on GitHub.
