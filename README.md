# MMM Portfolio Website

This repo is a static website for marketing mix modeling and attribution work.

## What is inside

- A landing page: index.html
- Notebook pages exported to html inside notebooks
- Images extracted from notebook outputs inside assets
- Project docs inside docs

## How to publish with GitHub Pages

1. Push this folder to a GitHub repo
2. In GitHub, open Settings then Pages
3. Source: Deploy from a branch
4. Branch: main and folder: root
5. Save

GitHub will give you a public url.

## Local preview

Open index.html in a browser.
